2. [nit] hooks/lib.ts:122: severity rank reads inherited Object properties (2/2 votes)
   class: prototype key lookup on untrusted input
   why: `const SEV = {...} as Record<string, number>` and `rank = SEV[String(sev)] ?? 0`. A model-supplied severity such as "constructor" or "toString" returns an inherited function, not undefined, so `?? 0` does not apply and `stronger` compares a function with a number.
