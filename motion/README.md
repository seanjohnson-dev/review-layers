# The film

A 69-second piece with no narration and no captions. Every word on screen is a real string: the mod's own `hooks/register.tsx`, a small demo project with planted bugs, and eight captured runs of the mod on it (`capture/`): the feature diff, the red run, the fix diff, the tests, the green run, the refused push, the approval, the push going through.

Nothing in it is generated by a model. It is a three.js page (`land2.html`) in which every frame is a pure function of time, rendered frame by frame in headless Chrome with media-studio's `render.mjs`, then given synthesised sound (`sound.py`, ffmpeg generators: room tone, key ticks, a pass per layer, a hit per finding, a buzz on the refusal, a note on green).

```bash
node build-data.mjs                         # inlines the real text into data.js
node <studio>/tools/render.mjs land2.html --preset landscape --duration 69 --out out/film-silent.mp4
python3 sound.py                            # out/sound.m4a
ffmpeg -i out/film-silent.mp4 -i out/sound.m4a -c:v copy -c:a aac -shortest out/film.mp4
```

`land2.html?t=30` shows one moment, for stills. `land2.html?play` plays it live in a browser.

The demo project the runs were captured on (`tillpoint`, a point-of-sale service in cents with a rand/cents mix-up, an unclamped discount and a fractional average) is the one the film shows being reviewed; `capture/self-*.txt` are the mod's later runs on its own repository.

`land.html` is the first, narrated version, kept for the record.
